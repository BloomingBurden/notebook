# Smart Notebook

[Открыть блокнот](https://bloomingburden.github.io/notebook/)

Блокнот для конспектов, фрагментов кода и интервального повторения. Заметки хранятся в текущем браузере. Для резервной копии или переноса на другой компьютер используйте **Настройки → Экспорт JSON** и **Импорт JSON**. Если раньше вы открывали блокнот как HTML-файл, экспортируйте заметки в старом окне и импортируйте их на сайте.

## Редактор

- **Текст** показывает исходный Markdown, **Рядом** показывает его и предпросмотр, **Чтение** выводит оформленную заметку.
- Для фрагмента кода выделите текст, выберите язык и нажмите **Блок кода**. Внутри блока `Tab` и `Shift+Tab` меняют отступ, `Enter` сохраняет отступ строки, `Esc` выводит фокус из поля. Подсвеченный блок в предпросмотре можно скопировать кнопкой.
- Панель форматирования поддерживает заголовки, списки, чек-листы, ссылки, цитаты и таблицы. `Ctrl/Cmd+S` сохраняет заметку сразу, `Ctrl/Cmd+K` открывает поиск. Изменения также сохраняются автоматически.

## Настройка повторения

1. Откройте нужную заметку, включите **Повторение** под редактором и нажмите **Начать цикл**.
2. Первый этап доступен сразу. Нажмите **Отметить выполненным**, чтобы запланировать следующий этап через 25 минут. Далее интервалы между отметками составят 1, 17 и 75 дней.
3. Просроченные заметки собраны в разделе **К повторению**. Нажатие на системное уведомление открывает заметку или список, если одновременно подошло несколько сроков.

Пока этап просрочен, системное напоминание повторяется каждые 30 минут. После отметки **Отметить выполненным** напоминания для текущего этапа прекращаются до срока следующего.

## Уведомления с открытой вкладкой

На сайте нажмите **Уведомления → Разрешить на сайте → Разрешить**. Кнопка **Проверить** отправит тестовое системное уведомление. Если разрешение уже заблокировано, измените его в настройках сайта рядом с адресной строкой.

## Уведомления с закрытой вкладкой

1. Скачайте и распакуйте [ZIP с GitHub](https://github.com/BloomingBurden/notebook/archive/refs/heads/main.zip).
2. В настольном Chrome введите `chrome://extensions`, в Edge — `edge://extensions`. Включите **Режим разработчика**, выберите **Загрузить распакованное расширение** и укажите папку `extension` внутри распакованного проекта.
3. Откройте или обновите [блокнот](https://bloomingburden.github.io/notebook/). Нажмите **Уведомления → Включить фоновые → Проверить**. Расписание передаётся расширению сразу и обновляется при изменениях.
4. Вкладку можно закрыть. Оставьте браузер запущенным. Если он был выключен или компьютер спал, просроченные напоминания появятся после возвращения. Если тестовое уведомление не видно, проверьте уведомления для Chrome или Edge и режим «Не беспокоить» в системе.

Если расширение уже установлено, скопируйте файлы из новой папки `extension` в ту папку, которую выбрали при установке. Нажмите **Обновить** ↻ на карточке расширения в браузере, затем обновите блокнот и нажмите **Уведомления → Проверить**. Повторные напоминания при закрытой вкладке доступны с версии 1.1.0.

Расширение хранит названия заметок и сроки локально в браузере. Текст заметок остаётся в блокноте.

Инструкции разработчиков браузеров: [Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked), [Edge](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading).

## Локальный запуск

Для редактирования можно открыть `notebook_app_rich_improved.html` напрямую. Для проверки уведомлений запустите статический сервер из корня проекта и откройте localhost.

```powershell
npx --yes http-server . -a 127.0.0.1 -p 8080 -c-1
```

Страница и расширение работают без сборки. В `assets/vendor/` лежат браузерные сборки [markdown-it 15.0.3](https://www.npmjs.com/package/markdown-it/v/15.0.3) и [Highlight.js 11.12.0](https://www.npmjs.com/package/@highlightjs/cdn-assets/v/11.12.0) с лицензиями.
